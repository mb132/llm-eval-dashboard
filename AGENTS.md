# Repository guidance

## Commit messages

Use Conventional Commit prefixes for commits in this repository:
`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, `build:`,
`ci:`, or `perf:`. Write a short, imperative summary after the prefix.

Choose the prefix that describes the main change. For example:

- `feat: add evaluation export`
- `fix: handle missing token usage`
- `docs: clarify local setup`
- `chore: update development tooling`

## Wiki documentation

This project has a [GitHub Wiki](https://github.com/mb132/llm-eval-dashboard/wiki)
in a separate Git repository. When a major feature changes setup, user workflows,
configuration, or reported results, update the relevant wiki pages as part of
that work. Keep the wiki home page and sidebar links current when adding pages.
